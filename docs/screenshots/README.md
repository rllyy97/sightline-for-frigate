# Standalone preview screenshots

Captured on October 31, 2026 from the production card bundle in the local preview.
All video, faces, camera identities, and backend data are synthetic.

Desktop captures use a 1440×900 browser viewport and include the header and card,
with unused space below the card cropped. Mobile uses a 390×844 viewport.

- `desktop-clips.jpg`: single-camera Clips workspace and persistent timeline.
- `desktop-clip-playback.jpg`: a clip opened from the browser and decoded locally.
- `desktop-reviews.jpg`: reviewed and unreviewed review entries.
- `desktop-recording-playback.jpg`: playback of a completed recording hour.
- `desktop-multiview.jpg`: three cameras with the aggregate Clips browser.
- `desktop-empty-library.jpg`: connected cameras with no retained media.
- `mobile-light-clips.jpg`: Clips on a narrow viewport in the light theme.

These document the development environment, including current card behavior.
Selected-row styling and viewer/timeline synchronization are separate follow-ups.
